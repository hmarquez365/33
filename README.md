# Behind Every Plate — Barilla packaging redesign project

A responsive, multilingual static website designed to be opened from a QR code on a redesigned pasta package.

## Files
- `index.html` — semantic page structure and content
- `css/style.css` — responsive visual system and layout
- `js/script.js` — language switching, farmer profile dialogs, interactive map and cooking timer
- `assets/images/` — reserved for local image assets (the current prototype uses remotely hosted Unsplash photographs)

## Run locally
Open `index.html` in a browser. No build step, backend, framework or package installation is required.

## Publish with GitHub Pages
1. Create a new repository on GitHub, for example `behind-every-plate`.
2. Upload the contents of this folder. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment and copy the public URL shown in the Pages panel. It normally follows `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
7. Generate a QR code using that exact URL. Test it on a phone before printing.

## Content and verification
- The three farmer profiles and all quotations are explicitly fictional educational narratives.
- The 2025 figures shown (programme start in 2010; almost 7,000 farmers; 816,000 tonnes of cereals and basil) are Group-wide Barilla Sustainable Farming figures across strategic supply chains. They are **not** presented as durum-wheat-only figures.
- Barilla-specific statements are limited to publicly described programme elements: cultivation guidelines/contracts, agronomic specifications, digital support and farmer collaboration. No direct financing, guaranteed prices or universal contract conditions are claimed.
- General sustainability practices are educational explanations, not claims that each practice is implemented by Barilla in every region.
- Review the official source links in the website footer before final academic submission.
